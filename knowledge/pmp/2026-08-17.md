# PMP · 第 5 课：成本管理（估算 / 预算 / 挣值 EVM）（第 1 轮）

> **承接第 4 课** —— 第 4 课我们用关键路径法算出项目最短工期，并锁定了进度基准。但"多久做完"之外，老板更常问的是"花多少钱、值不值"。这就是本课「成本管理（Cost Management）」：从估算每一笔花费，到用**挣值管理（EVM）**在过程中实时判断"钱花得值不值、进度赶没赶上"。

## 一、导语
电商网站预算 ¥120 万，到第 3 个月末老板问："钱花了一半，活干了多少？"——凭感觉答不上来。成本管理用三层动作回答：先**估算**每一项成本，再**汇总成预算基准**，最后用挣值把"计划、实际、完成"三者放一起算偏差。本课重点落在 EVM 的 SPI / CPI。

## 二、核心知识点

### 1. 成本三动作
- **估算成本（Estimate）**：对活动 / 工作包估出金额（精度随项目推进提高）。
- **制定预算（Determine Budget）**：汇总估算 + **应急储备（Contingency）** → **成本基准（Cost Baseline）**；再加**管理储备（Management Reserve）** = 项目总预算。BAC（完工预算）= 成本基准总额。
- **控制成本（Control）**：用挣值监控、预测、纠偏。

### 2. 估算技术
类比估算（快、粗）、参数估算（单位 × 数量）、**自下而上（最准）**、三点估算（期望 + 储备）。

### 3. 挣值管理 EVM（核心）
三个基准量：
- **PV（计划价值 Plan Value）**：到某时点"计划该完成的工作"的预算。
- **EV（挣值 Earned Value）**：到某时点"实际已完成工作"的预算（按预算价算，非实际花销）。
- **AC（实际成本 Actual Cost）**：到某时点实际花的钱。

四大指标：
- 成本偏差 `CV = EV − AC`；成本绩效 `CPI = EV / AC`（<1 超支）
- 进度偏差 `SV = EV − PV`；进度绩效 `SPI = EV / PV`（<1 滞后）
- 完工估算 `EAC`、完工尚需 `ETC`、完工尚需绩效 `TCPI`。

## 三、真实案例：SPI / CPI 计算

**场景**：电商网站项目 BAC = ¥120 万，计划第 3 个月末（时点 T）完成 45% 的工作。T 时点实测：
- PV = ¥50 万（计划该完成 50 万预算的工作）
- AC = ¥55 万（实际已花 55 万）
- EV = ¥45 万（实际完成工作的预算值）

**计算**：
- CV = 45 − 55 = **−10 万**（成本超支 10 万）
- SV = 45 − 50 = **−5 万**（进度落后 5 万当量）
- CPI = 45 / 55 = **0.82**（每花 1 元只产出 0.82 元价值，超支）
- SPI = 45 / 50 = **0.90**（进度仅完成计划的 90%）

**预测（按当前绩效延续）**：
- EAC = BAC / CPI = 120 / 0.82 ≈ **¥146 万**（预计超预算 26 万）
- ETC = EAC − AC = 146 − 55 = **¥91 万**
- 若要硬拉回原预算：TCPI = (BAC − EV) / (BAC − AC) = (120 − 45) / (120 − 55) = 75 / 65 ≈ **1.15**（剩余工作需达到 1.15 的绩效，极难）。

**纠偏建议**：CPI=0.82 已持续偏低，须削减非关键路径范围或提升效率；SPI=0.90 可借第 4 课关键路径上的浮动活动赶工。把"感觉超支"变成"量化到 26 万、可决策的纠偏"。

## 四、与前后知识的联系
- **向后**：EVM 监控结果会回流到整合管理的"监控项目工作 / 实施整体变更控制"，触发变更。
- **向前（第 4 课）**：进度基准是 SPI 的分母（PV）来源；成本基准是 BAC 来源——进度与成本在 EVM 里汇合。

## 五、小结与延伸
- **一句话**：EVM 用 PV / EV / AC 三量，CPI 看钱、SPI 看进度，<1 即报警。
- **延伸**：PMBOK® Guide 第 7 章「成本管理」；进一步学 EAC 的多种预测公式（典型 / 非典型偏差）。
- **下期预告**：第 6 课《质量管理》——规划 / 保证 / 控制，把缺陷率管到可接受水平。
