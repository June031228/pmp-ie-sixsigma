# 六西格玛黑带 · 第 4 课：Analyze·因果图与假设检验（第 1 轮）

## 导语：Measure 给了基线，Analyze 要回答"为什么"

上一课（第 3 课 Measure）我们完成了「猎影」项目的测量系统分析和基线计算：

- **GRR = 6.2%**（合格），分光光度计可信；
- **基线 Cpk = 0.153**，Ppk = 0.136，过程能力远低于六西格玛目标；
- **当前不良率 34.2%**——每 3 件就有 1 件色差超标。

现在问题来了：**均值 0.87 ΔE、标准差 0.319**，这些变异到底从哪儿来？是模具温度波动？色母批次差异？预干燥不充分？还是操作员手法？

Measure 阶段告诉我们"差多远"，Analyze 阶段要告诉我们"为什么差"。本课两大工具：

1. **因果图（Cause-and-Effect Diagram / 鱼骨图 / Ishikawa Diagram）**：系统性地罗列所有可能的根因；
2. **假设检验（Hypothesis Testing，以 t 检验为例）**：用数据验证哪些根因是"真凶"。

## 核心知识点

### 1. 因果图：根因的"穷举器"

因果图由日本质量管理学者石川馨（Kaoru Ishikawa）于 1953 年提出，也叫鱼骨图（Fishbone Diagram）。

#### 1.1 结构

```
                        人（Man）
                          │
                   ───────┤
          方法（Method）──┤── 问题（Effect）
                   ───────┤
                        机器（Machine）
                          │
    材料（Material）──────┤
                   ───────┤
                       测量（Measurement）
                          │
                    环境（Environment）
```

主骨 = 问题陈述；每根大骨 = 一个类别（6M）；每根大骨上的小骨 = 该类别的具体原因。

#### 1.2 6M 分类法

| 类别 | 英文 | 制造业典型因素 |
|------|------|---------------|
| **人** | Man | 操作员技能、疲劳、培训 |
| **机** | Machine | 设备精度、磨损、参数设置 |
| **料** | Material | 原料批次、供应商、含水率 |
| **法** | Method | 工艺规程、作业标准、参数 |
| **测** | Measurement | 量具精度、抽样方案 |
| **环** | Environment | 温湿度、粉尘、照明 |

> **最佳实践**：鱼骨图不是一个人在办公室画的——开一场**头脑风暴会**，让产线操作员、工艺工程师、品保一起参与。原因写得越具体越好（"操作员未校准色母称量台"比"人员问题"有用得多）。

#### 1.3 从鱼骨图到验证清单

鱼骨图列出 20~30 个潜在根因后，用** Pareto 投票**或**FMEA 风险优先数（RPN）**筛选出 5~8 个高优先原因，进入假设检验验证。

### 2. 假设检验：从"猜测"到"证据"

#### 2.1 假设检验的逻辑

| 步骤 | 内容 | 本课示例 |
|------|------|---------|
| 1. 建立假设 | H₀（零假设）和 H₁（备择假设） | H₀: μ_A = μ_B（两模具色差均值相等）；H₁: μ_A ≠ μ_B |
| 2. 选择检验方法 | 根据数据类型和比较对象 | 双样本 t 检验（两组连续数据比较均值） |
| 3. 确定显著性水平 | α（通常取 0.05） | α = 0.05 |
| 4. 计算统计量和 p 值 | 用公式或软件 | t = -3.27, p = 0.002 |
| 5. 决策 | p < α → 拒绝 H₀ | 0.002 < 0.05 → 拒绝 H₀，两模具色差有显著差异 |

> **核心原则**：我们永远无法"证明"H₀ 为真——只能说"没有足够证据拒绝它"。拒绝 H₀ = 找到了**统计显著**的差异。

#### 2.2 两类错误

| | H₀ 为真 | H₁ 为真 |
|---|---------|---------|
| **不拒绝 H₀** | ✓ 正确 | **第二类错误（β）**：漏掉了真因 |
| **拒绝 H₀** | **第一类错误（α）**：冤枉了好人 | ✓ 正确（检出力 = 1-β） |

> α = 0.05 意味着：如果 H₀ 为真（两组没差异），我们有 5% 的概率"误判为有差异"。

#### 2.3 双样本 t 检验（Two-Sample t-Test）

用于比较两组独立样本的均值是否有显著差异。

**检验统计量**：

$$
t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}
$$

自由度用 Welch 近似：

$$
df = \frac{(s_1^2/n_1 + s_2^2/n_2)^2}{\frac{(s_1^2/n_1)^2}{n_1-1} + \frac{(s_2^2/n_2)^2}{n_2-1}}
$$

**前提条件**：
- 数据连续且近似正态（或样本量 ≥ 30，中心极限定理保证）；
- 两组独立；
- 方差齐性（若不等，用 Welch 修正）。

#### 2.4 方差分析（ANOVA）预告

当需要同时比较**3 组以上**均值时，不能用多次 t 检验（会放大 α 错误），而要用 ANOVA（将在第 8 课详细讲解）。本课先掌握 t 检验。

### 3. Analyze 阶段的标准工作流

```
鱼骨图头脑风暴 → 筛选高优先原因（5~8 个）
                      │
                      ▼
              分类型数据：卡方检验 / 逻辑回归
              连续型数据：t 检验 / ANOVA
                      │
                      ▼
              确认统计显著的根因（p < α）
                      │
                      ▼
              排序根因影响度（效应大小）
                      │
                      ▼
              Analyze 关门，进入 Improve
```

## 真实案例：常州注塑厂「猎影」项目·Analyze 阶段

### 背景

Measure 阶段确认基线 Cpk = 0.153、不良率 34.2%。黑带张工组织了一场头脑风暴会，参与人：工艺工程师 2 名、注塑班长 2 名、品保工程师 2 名、色母供应商技术代表 1 名。

### 第一步：鱼骨图——"色差超标"的根因穷举

| 大骨 | 小骨（具体原因） | 投票优先级 |
|------|-----------------|-----------|
| **人（Man）** | • 操作员调色母称量手法不一致 | 中 |
| | • 换班时注射压力设置被改 | 低 |
| **机（Machine）** | • **#3 注塑机模温控制器波动 ±5℃** | **高** |
| | • 螺杆磨损导致混料不匀 | 中 |
| | • **#7 注塑机保压时间偏差 2s** | **高** |
| **料（Material）** | • **色母批次间 ΔE 波动** | **高** |
| | • ABS 颗粒含水率超标（>0.05%） | 中 |
| | • 回收料掺混比例不稳定 | 低 |
| **法（Method）** | • 螺杆转速未按色母牌号调整 | 中 |
| | • **预干燥温度 80℃ 偏低，建议 85~90℃** | **高** |
| | • 背压设置 4 bar，偏低 | 中 |
| **测（Measurement）** | • 分光光度计未定期校准 | 低（GRR 已合格） |
| **环（Environment）** | • 车间温度 15~32℃ 季节波动 | 中 |
| | • 冷却水温波动影响模温 | 低 |

**筛选结果**：5 个高优先原因进入假设检验——

| 编号 | 假设 | 检验方法 |
|------|------|---------|
| H1 | #3 机与 #5 机色差均值有显著差异 | 双样本 t 检验 |
| H2 | 色母批次 A 与批次 B 的色差均值有显著差异 | 双样本 t 检验 |
| H3 | 预干燥温度 80℃ vs 88℃ 对色差有显著影响 | 双样本 t 检验 |
| H4 | #7 机保压时间 8s vs 10s 对色差有显著影响 | 双样本 t 检验 |
| H5 | 不同操作员对色差无影响 | 已在 GRR 中排除（AV% = 2.4%） |

### 第二步：假设检验验证

#### H1：#3 机 vs #5 机色差对比

各取 30 件（3 天、10 件/天），记录 ΔE：

| 统计量 | #3 机 | #5 机 |
|--------|-------|-------|
| 样本量 n | 30 | 30 |
| 均值 x̄ | 0.98 | 0.72 |
| 标准差 s | 0.241 | 0.198 |
| 方差 s² | 0.0581 | 0.0392 |

**Welch 双样本 t 检验**：

$$
t = \frac{0.98 - 0.72}{\sqrt{\frac{0.0581}{30} + \frac{0.0392}{30}}} = \frac{0.26}{\sqrt{0.001937 + 0.001307}} = \frac{0.26}{\sqrt{0.003244}} = \frac{0.26}{0.0570} = 4.56
$$

$$
df = \frac{(0.001937 + 0.001307)^2}{\frac{0.001937^2}{29} + \frac{0.001307^2}{29}} = \frac{0.00001052}{0.0000001294 + 0.0000000589} = \frac{0.00001052}{0.0000001883} = 55.9 \approx 56
$$

查 t 分布表（双尾，df=56）：t_0.025,56 ≈ 2.003。

**t = 4.56 > 2.003 → p < 0.001**

**结论**：拒绝 H₀，#3 机与 #5 机色差均值有**高度显著**差异。#3 机均值 0.98 逼近上限 1.0，是主要问题源。

#### H2：色母批次 A vs 批次 B

各取 25 件，同一机台（#5 机），其余条件一致：

| 统计量 | 批次 A | 批次 B |
|--------|--------|--------|
| n | 25 | 25 |
| x̄ | 0.69 | 0.81 |
| s | 0.186 | 0.203 |

$$
t = \frac{0.69 - 0.81}{\sqrt{\frac{0.0346}{25} + \frac{0.0412}{25}}} = \frac{-0.12}{\sqrt{0.001384 + 0.001648}} = \frac{-0.12}{0.0551} = -2.18
$$

df ≈ 47.3, t_0.025,47 ≈ 2.012。

**t = -2.18, |t| > 2.012 → p ≈ 0.035 < 0.05**

**结论**：拒绝 H₀，色母批次间有**显著**差异。批次 B（x̄=0.81）明显差于批次 A（x̄=0.69）。

#### H3：预干燥温度 80℃ vs 88℃

各取 20 件，同一机台（#3 机），同一色母批次，仅改预干燥温度：

| 统计量 | 80℃ | 88℃ |
|--------|-----|-----|
| n | 20 | 20 |
| x̄ | 0.95 | 0.78 |
| s | 0.262 | 0.214 |

$$
t = \frac{0.95 - 0.78}{\sqrt{\frac{0.0686}{20} + \frac{0.0458}{20}}} = \frac{0.17}{\sqrt{0.003430 + 0.002290}} = \frac{0.17}{0.0755} = 2.25
$$

df ≈ 36.5, t_0.025,36 ≈ 2.028。

**t = 2.25 > 2.028 → p ≈ 0.031 < 0.05**

**结论**：拒绝 H₀，预干燥温度 88℃ 显著降低色差。80℃ 时 ABS 颗粒含水率偏高，导致注射时产生气泡和色差。

#### H4：保压时间 8s vs 10s（#7 机）

各取 20 件：

| 统计量 | 8s | 10s |
|--------|-----|-----|
| n | 20 | 20 |
| x̄ | 0.84 | 0.80 |
| s | 0.230 | 0.225 |

$$
t = \frac{0.84 - 0.80}{\sqrt{\frac{0.0529}{20} + \frac{0.0506}{20}}} = \frac{0.04}{0.0721} = 0.55
$$

df ≈ 38.0, t_0.025,38 ≈ 2.024。

**t = 0.55 < 2.024 → p ≈ 0.587 > 0.05**

**结论**：不拒绝 H₀，保压时间 8s 与 10s 对色差**无显著差异**。保压时间不是色差的主要根因。

### 第三步：根因排序与结论

| 根因 | p 值 | 效应大小（均值差） | 优先级 |
|------|------|-------------------|--------|
| **#3 机 vs #5 机** | < 0.001 | 0.26 ΔE | **P1（最大根因）** |
| **预干燥温度 80℃ vs 88℃** | 0.031 | 0.17 ΔE | **P2** |
| **色母批次 A vs B** | 0.035 | 0.12 ΔE | **P3** |
| 保压时间 8s vs 10s | 0.587 | 0.04 ΔE | 排除 |

> **关键洞察**：#3 注塑机是最大的变异源（均值差 0.26，是第二大根因的 1.5 倍），其次是预干燥温度和色母批次。保压时间可以排除——这避免了一个"看起来合理但没有数据支撑"的改善方向。

### 汇总：Analyze 阶段交付物

| 交付物 | 结果 |
|--------|------|
| 鱼骨图 | 6M 分类，20 个潜在根因 |
| 筛选高优先假设 | 4 个进入检验 |
| t 检验结果 | 3 个显著（#3 机、预干燥温度、色母批次），1 个不显著（保压时间） |
| 根因排序 | P1: 机台 #3；P2: 预干燥温度；P3: 色母批次 |
| Analyze 关门日期 | 2026/11/15 |

## 与前后知识的联系

### 向上承接（第 3 课 Measure）

Measure 阶段给了我们基线数字（Cpk=0.153、不良率 34.2%），但没告诉我们"差在哪"。Analyze 阶段的鱼骨图 + t 检验把"模糊的变异"分解为"可定位的根因"——这是从**描述性统计**到**推断性统计**的跨越。

### 向下衔接（第 5 课 Improve）

Analyze 确认了 3 个根因（#3 机台、预干燥温度、色母批次），下一课进入 **Improve 阶段**——用 DOE（实验设计）找到最优参数组合，把 Cpk 从 0.153 拉到目标值。

### 与 PMP 的呼应

- **PMP 第 9 课（风险管理）** 讲「风险登记册」——鱼骨图是风险的"根因分析工具"，PMP 中的定性风险分析 ≈ 六西格玛的因果图筛选；
- **PMP 第 5 课（成本 EVM）** 讲"偏差分析"——假设检验是统计版的偏差分析。

> **跨课洞察**：鱼骨图 + 假设检验 = **质量版的"根因分析（Root Cause Analysis）"**，在项目管理中同样适用。

## 小结与延伸阅读

**本课要点**：

1. **鱼骨图**用 6M 分类系统穷举根因，靠头脑风暴而非个人经验；
2. **假设检验**用数据验证哪些根因是"真凶"——p < α（0.05）才算显著；
3. **双样本 t 检验**比较两组均值差异，公式 t = (x̄₁-x̄₂) / √(s₁²/n₁ + s₂²/n₂)；
4. **第一类错误**（α=冤枉好人）和**第二类错误**（β=漏掉真因）是检验的代价天平；
5. 「猎影」项目确认三大根因：#3 机台变异、预干燥温度偏低、色母批次不稳定。

**关键术语**：因果图（Cause-and-Effect Diagram / Ishikawa Diagram）、6M 分类法、假设检验（Hypothesis Testing）、零假设（Null Hypothesis, H₀）、备择假设（Alternative Hypothesis, H₁）、p 值（p-value）、显著性水平（α）、第一类错误（Type I Error）、第二类错误（Type II Error）、检出力（Power = 1-β）、双样本 t 检验（Two-Sample t-Test）、Welch 修正。
