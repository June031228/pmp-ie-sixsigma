# 工业工程 · 第 6 课：设施规划与物流·SLP（第 1 轮）

## 导语：从“时间平衡”跨入“空间布局”

第 5 课我们把电动牙刷装配线从 8 工位优化到 7 工位，线平衡率从 71% 提升到 96%。但 IE 工程师到现场一看：工位 2 的焊接设备在车间东头，工位 3 的检测台在西头，半成品得推着小车穿过大半个厂房；仓库在二楼，产线在一楼，每补一次料要爬 30 级台阶。时间省下来的效益，全被搬运吃掉了。

本课进入工业工程第 6 课：**设施规划与物流分析（Facility Planning & Logistics）**，核心方法是 **SLP（Systematic Layout Planning，系统布局规划）**。目标：把人员、设备、物料、仓库放到空间上最合理的位置，让搬运距离最短、物流交叉最少、在制品不积压。

---

## 核心知识点

### 1. 设施规划的三大目标

| 目标 | 含义 | 衡量指标 |
|------|------|----------|
| **最小化物料搬运** | 减少搬运距离、次数和强度 | 吨·米/件、搬运次数/天 |
| **最大化空间利用率** | 单位面积产出最高 | 件/m²·年、设备密度 |
| **保证安全与柔性** | 消防通道、未来扩产预留 | 通道宽度、可重组指数 |

### 2. SLP 的六步法

由 Richard Muther 于 1961 年提出，是设施规划最系统的框架：

**Step 1：P-Products（产品分析）**
- 产品种类、产量、工艺路线；
- 决定布局类型：产品导向（流水线）vs 工艺导向（机群式）vs 成组单元（Cell）。

**Step 2：Q-Quantity（产量分析）**
- 高产量 → 产品导向布局（流水线，固定路径）；
- 多品种小批量 → 工艺导向或成组单元（灵活路径）。

**Step 3：R-Routing（工艺路线）**
- 绘制从原材料到成品的工艺流程图；
- 统计每两道工序之间的物流强度。

**Step 4：S-Supporting Services（辅助服务）**
- 仓库、质检、维修、办公、休息区的位置需求。

**Step 5：T-Time（时间安排）**
- 生产节拍、换型时间、物料配送频率。

**Step 6：Layout Design（布局设计）**
- 综合 PQRST，生成候选布局方案，评估选优。

### 3. 物流强度分析与从至表（From-To Chart）

把各作业单位（部门/工位/设备）之间的物流量汇总成矩阵：

| 从 \ 至 | 原材料库 | 下料 | 冲压 | 焊接 | 涂装 | 总装 | 成品库 |
|---------|----------|------|------|------|------|------|--------|
| 原材料库 | — | 120 | 0 | 0 | 0 | 0 | 0 |
| 下料 | 0 | — | 120 | 0 | 0 | 0 | 0 |
| 冲压 | 0 | 0 | — | 100 | 0 | 0 | 20 |
| 焊接 | 0 | 0 | 0 | — | 100 | 0 | 0 |
| 涂装 | 0 | 0 | 0 | 0 | — | 100 | 0 |
| 总装 | 0 | 0 | 0 | 0 | 0 | — | 100 |
| 成品库 | 0 | 0 | 0 | 0 | 0 | 0 | — |

> 单位：托盘/天。表中可见“下料→冲压”和“冲压→焊接”是物流主干。

**物流强度等级**（Muther 的 A-E-I-O-U-X 分级）：

| 等级 | 含义 | 距离要求 |
|------|------|----------|
| A | 绝对必要紧邻 | 0–1 m |
| E | 特别重要靠近 | 1–3 m |
| I | 重要 | 3–5 m |
| O | 一般 | 5–10 m |
| U | 不重要 | 任意 |
| X | 不希望靠近 | 尽量远离 |

### 4. 活动关系图与面积拼块法

**活动关系图（Activity Relationship Diagram）**：
用节点代表作业单位，连线标注 A/E/I/O/U/X 关系，直观展示谁该挨着谁。

**面积拼块法（Area Allocation）**：
1. 按设备清单计算每个单位所需面积；
2. 把关系图转化为“面积拼块”，A 级关系的两个单位共享边界；
3. 用试错或计算机辅助（如 AutoCAD、FactoryFLOW、VisTable）排布；
4. 计算总搬运距离 = $\sum (\text{流量}_{ij} \times \text{距离}_{ij})$，选最小者。

### 5. 布局类型选择

| 布局类型 | 适用场景 | 优点 | 缺点 |
|----------|----------|------|------|
| **产品导向** | 大批量、标准化产品 | 物流顺畅、在制品少、周期短 | 柔性差、投资大 |
| **工艺导向** | 多品种小批量、定制 | 柔性高、设备共用 | 搬运多、在制品多、周期长 |
| **成组单元（Cell）** | 中等批量、相似零件族 | 兼顾效率与柔性 | 需成组技术支撑 |
| **固定位置** | 大型产品（船舶、飞机） | 产品不动 | 人员设备移动、空间占用大 |

## 真实案例：五金件加工车间的 SLP 改造

某五金制品厂（广东佛山，年产值 3,200 万）有一个 1,200 m² 的机加车间，原有布局是**工艺导向**（所有车床放一起、所有铣床放一起），导致一个零件从原材料到成品要跨车间搬运 6 次，平均搬运距离 87 米。

### 现状分析

**产品 P**：3 大系列、12 个 SKU，月产 4,800 件；
**产量 Q**：A 系列（标准件）占 60%，B/C 系列（定制件）各占 20%；
**路线 R**：
- A 系列：原材料 → 下料 → 冲压 → 焊接 → 涂装 → 总装 → 成品；
- B 系列：原材料 → 下料 → 车削 → 铣削 → 焊接 → 涂装 → 总装；
- C 系列：原材料 → 下料 → 冲压 → 铣削 → 焊接 → 涂装 → 总装。

**从至表（托盘/天）**：

| 从 \ 至 | 原材料库 | 下料 | 冲压 | 车削 | 铣削 | 焊接 | 涂装 | 总装 | 成品库 |
|---------|----------|------|------|------|------|------|------|------|--------|
| 原材料库 | — | 48 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 下料 | 0 | — | 29 | 0 | 0 | 0 | 0 | 0 | 0 |
| 冲压 | 0 | 0 | — | 0 | 10 | 29 | 0 | 0 | 0 |
| 车削 | 0 | 0 | 0 | — | 0 | 10 | 0 | 0 | 0 |
| 铣削 | 0 | 0 | 0 | 0 | — | 20 | 0 | 0 | 0 |
| 焊接 | 0 | 0 | 0 | 0 | 0 | — | 48 | 0 | 0 |
| 涂装 | 0 | 0 | 0 | 0 | 0 | 0 | — | 48 | 0 |
| 总装 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | — | 48 |

**物流强度分级**：
- A（绝对必要紧邻）：下料-冲压、冲压-焊接、焊接-涂装、涂装-总装、总装-成品库；
- E（特别重要）：车削-焊接、铣削-焊接；
- X（不希望靠近）：涂装-原材料库（粉尘污染）。

### 改善方案

**方案：混合布局——产品导向主线 + 工艺导向辅线**

1. **A 系列（60% 产量）建专用流水线**：
   原材料库 → 下料 → 冲压 → 焊接 → 涂装 → 总装 → 成品库，一字排开，占用 600 m²；

2. **B/C 系列共用柔性加工区**：
   车削、铣削设备按工艺导向集中，但通过**成组单元（Cell）**组织：
   - Cell 1：下料 + 车削 + 焊接（服务 B 系列）；
   - Cell 2：下料 + 冲压 + 铣削 + 焊接（服务 C 系列）；
   两个 Cell 共用涂装和总装线（与 A 线错峰）。

3. **仓库位置**：
   原材料库放在下料区入口（东侧），成品库放在总装线末端（西侧），形成**单向物流**（东→西），避免交叉。

### 改善效果

| 指标 | 改善前 | 改善后 | 变化 |
|------|--------|--------|------|
| 平均搬运距离 | 87 m | **34 m** | −61% |
| 搬运次数/件 | 6 次 | **3 次** | −50% |
| 在制品库存 | 320 件 | **140 件** | −56% |
| 生产周期 | 5.2 天 | **2.8 天** | −46% |
| 车间面积利用率 | 58% | **78%** | +20 pp |
| 年搬运成本 | ¥18.6 万 | **¥7.2 万** | −61% |

**投资回报**：布局改造费用（设备搬迁+地面标线+货架）约 ¥12 万，一年半回收。

## 与前后知识的联系

- **向前回溯（第 5 课 → 本课）**：第 5 课解决了“每个工位做多长时间”，本课解决“这些工位放在哪”——时间平衡后，空间布局决定了时间优势能否兑现。
- **向后衔接（本课 → 第 7 课）**：布局定了，人要在工位上干 8 小时——下一步是**人机工程学**，研究工位高度、座椅、照明、操作姿势，让人在空间里干得不累、不伤、高效。
- **向上呼应（第 2 课 → 本课）**：第 2 课用流程程序图分析“流程级”浪费（搬运、等待、检验），本课用 SLP 把“搬运”这一最大浪费从源头压缩——布局是流程的物理载体。

## 小结与延伸阅读

**小结**：

1. SLP 六步法（P-Q-R-S-T-Layout）是设施规划的系统框架，核心是“物流强度决定位置关系”；
2. 从至表和 A-E-I-O-U-X 关系图把定性经验变成定量决策；
3. 布局类型没有绝对好坏：大批量选产品导向，多品种选工艺导向或成组单元；
4. 改善后必须用“吨·米/件”或“搬运次数”验证，避免“看起来顺，实际更绕”。

**延伸阅读**：

- Muther, R. (1973). *Systematic Layout Planning* —— SLP 原典，工业工程必读；
- Tompkins, J. A. et al. *Facilities Planning*（最新版）—— 当代标准教材，含计算机辅助布局；
- 现场工具：VisTable、FactoryFLOW、AutoCAD 工厂布局插件；
- 进阶：CRAFT（Computerized Relative Allocation of Facilities Technique）算法，用计算机迭代优化布局。
