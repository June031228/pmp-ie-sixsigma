# 工业工程 · 第 4 课：动作研究·动素 Therbligs（第 1 轮）

## 导语：把秒表伸进"手指"里

第 3 课我们用秒表把"应该做多长时间"钉在了"标准工时"上。但秒表只能告诉你平均耗时，看不见操作员手在空中乱抓、零件掉头重插的"隐藏浪费"。

本课进入工业工程第 4 课：**动作研究（Motion Study）与动素分析（Therbligs）**。弗兰克·吉尔布雷斯（Frank Gilbreth）夫妇把任何手工操作分解成 17 种不能再分的基本动作——动素（Therbligs 是 Gilbreth 倒拼），再用"双手操作图"对照左右手每一瞬间在做什么。这一显微镜级的诊断，让"标准工时"背后的"标准动作"第一次有了可观察、可比较、可优化的对象。

## 核心知识点

### 1. 为什么需要动作研究

秒表能衡量**时间**，但看不见**动作**。同样的 12 秒，一种操作员装了 3 颗螺丝，另一种装了 5 颗——秒表结果差距也许只有 5%，而实际劳动效率相差 60%。动作研究的目的就是：

- 把所有手工操作拆到最小可观察单元（动素）；
- 用双手图同步观察左、右手任一瞬间在做什么；
- 依据"双手同时工作、动素经济原则"消除无效动素；
- 把改善后的新动作组合写进 SOP，作为后续时间研究和培训的依据。

### 2. 17 种基本动素（Therbligs 体系）

Gilbreth 把人手的动作归为 17 类，并赋予统一符号（左侧符号利于现场记录，右侧用字母代号利于程序图）：

| 类别 | 中文名 | 英文 | 符号 | 代号 |
|------|--------|------|------|------|
| **有效动素** | 伸手 | Reach | ⇒ 或波浪 | R |
| | 移物 | Move | ⇒ 实箭 | M |
| | 抓取 | Grasp | ⊂ 或勾 | G |
| | 对准 | Position | # | P |
| | 装配 | Assemble | ∪ | A |
| | 使用 | Use | ∪ 涂黑 | U |
| | 拆卸 | Disassemble | ∩ | DA |
| | 放开 | Release | ⌒ | RL |
| **辅助动素** | 寻找 | Search | ⊙ | SH |
| | 选择 | Select | → ？ | ST |
| | 检查 | Inspect | ◯ | I |
| | 预对 | Pre-position | 8 | PP |
| | 计划 | Plan | ∇ | PN |
| **延迟动素** | 故延（不可避免） | Unavoidable Delay | D 涂斜线 | UD |
| | 迟延（可避免） | Avoidable Delay | D | AD |
| | 持握 | Hold | ∩ 涂黑 | H |
| | 休息 | Rest | ⌒ 锯齿 | R |

> **关键判读口诀**：伸手 R、移物 M、抓取 G、对准 P、装配 A、检查 I、延迟 D。"R-M-G-P-A-I-D" 一气呵成，就能描述绝大多数手动工位。

### 3. 动素的经济原则

Gilbreth 给出了公认的动作经济原则，按优先级：

1. **取消（Eliminate）**：能不能不干？寻找、选择、迟延应优先消除；
2. **合并（Combine）**：两动作能否同时做？左右手对称安排；
3. **重排（Rearrange）**：换一下顺序能否缩短循环；
4. **简化（Simplify）**：剩下的能不能让手指路径更短、关节参与更少。

每种动素都有建议等级：

- **最经济**：移物（M）、装配（A）、放开（RL）、使用（U）；
- **次经济**：抓取（G）、对准（P）；
- **不经济**：寻找（SH）、选择（ST）、检查（I）、延迟（D）、持握（H）。

### 4. 双手操作图（Two-Hand Chart）

双手图用一张两栏纸条，左栏列左手动作、右栏列右手动作，各行同步在同一条时间轴上展开。约定的图形记号：

| 符号 | 含义 |
|------|------|
| ○ | 动作（操作） |
| → | 移物、抓取、松开 |
| ▽ | 空闲（Idle） |
| □ | 持物（Hold in hand） |

记录要点：

- 时基刻度对齐，左右手上下对齐在同一时间线上；
- 每段动作标上动素代号（R/M/G/P/A/I/D 等）；
- 每一周期为一栏，多次循环并排展示以揭示节拍不平衡。

**改善目标**：

- 双手利用率 ≥ 90%（同时都在动）；
- 单手空闲 ≤ 5%；
- 寻找、选择动作 = 0。

### 5. Simo Chart（动作改进图）

双手图诊断后，再用 Simo Chart 描绘"改善前 vs 改善后"的每个动素：
- 黑条 = 浪费（寻找、选择、迟延、持握）；
- 灰条 = 必要但可优化（伸手、对准）；
- 白条 = 有效（装配、使用、放开）。

## 真实案例：手机连接器插接工位的双手操作改善

某消费电子代工厂（深圳宝安，月产能 80 万台）有一条手机 Type-C 母座手工插接工位，单件标准工时在第 3 课被定为 **11.7 秒/件**。IE 团队用动作研究进一步压缩。

**原状态（Before）双手图节选（1 个周期，11.7 秒）**

| 时间 (s) | 左手 | 右手 |
|----------|------|------|
| 0.0–0.4 | 抓取连接器（G） | 等待（D-空闲） |
| 0.4–1.0 | 移向 PCB 定位孔（M） | 等待（D-空闲） |
| 1.0–1.6 | 对准+装配 母座（A） | 等待（D-空闲） |
| 1.6–2.0 | 压扣（RL） | 等待（D-空闲） |
| 2.0–2.6 | 等待（D-空闲） | 抓取 PCB（G）+ 移物（M） |
| 2.6–3.4 | 等待（D-空闲） | 对准+装配（A） |
| 3.4–4.0 | 调整定位（PP） | 压扣（RL） |
| 4.0–4.5 | 寻找下一颗连接器（SH） | 等待（D-空闲） |
| ... | ... | ... |

**问题识别**：

1. 右手空载时间高达 **58%**（6.8 s / 11.7 s）；
2. 左手"寻找"动作 0.5 秒 + 临时调整 0.2 秒，每周期浪费 0.7 秒；
3. 压扣环节需单手操作——另一只手确实"被迫空闲"。

**改善动作（After）**：

- 把 PCB 移到右手侧定位槽，使双手能**同时抓取母座**（消除"等待"和"调整定位"）；
- 在定位孔旁装一列 LED 镜片放大镜 + 反光板，配合超声波料斗（vibratory feeder），工人手一探就到位——**SH（寻找）从 0.5 s → 0 s**；
- 给桌面加装**气动预压模**，按脚踏即压扣，双手在压扣瞬间同步"放手"（RL），不需单手持握。

**改善后双手图节选（1 个周期，8.2 秒）**

| 时间 (s) | 左手 | 右手 |
|----------|------|------|
| 0.0–0.3 | 抓取连接器（G） | 抓取 PCB（G） |
| 0.3–0.7 | 移向定位槽（M） | 移向定位槽（M） |
| 0.7–1.2 | 对准+装配（A） | 对准+装配（A） |
| 1.2–1.5 | 压扣+放手（RL） | 压扣+放手（RL） |
| 1.5–1.8 | 视觉检查（I） | 视觉检查（I） |
| 1.8–1.9 | 放成品 | 放 PCB |
| ... | 双手利用率 92% | |

**效果**：

| 指标 | Before | After | 变化 |
|------|--------|-------|------|
| 单件标准工时 | 11.7 秒 | **8.2 秒** | −29.9% |
| 双手利用率 | 42% | **92%** | +50 pp |
| 寻找/选择动素 | 0.5 秒 | **0** | −100% |
| 单手空闲时间 | 6.8 秒 | **0.7 秒** | −89.7% |
| UPH（人均小时产能） | 308 件 | **439 件** | +42.5% |

12 名操作员的工位全部按新 SOP 上线后，该工段月产能从 80 万跃至 **110 万台/月**，半年累计节省工时费约 **¥186 万**。后续将这 8.2 秒的"动作标准"再拿回第 3 课的秒表流程做交叉验证，二者偏差 < 3%，证明新 SOP 既可执行、又可考核。

## 与前后知识的联系

- **向后衔接（本课 → 第 5 课）**：动素分析把单工位压缩到了极致，但整条线每个工位时长差距大——下一步就是按工位时间排序、做**生产线平衡**（Line Balancing），让节拍最长的工位（瓶颈）不再吃光其他人的等待。
- **向前回溯（第 3 课 → 本课）**：第 3 课用秒表得到"标准工时"，但秒表是黑盒平均值。本课把每秒钟拆成 17 种动素，看清楚"11.7 秒里有 6.8 秒是单手等"——这是秒表永远看不见的真相。
- **向上呼应（第 2 课 → 本课）**：第 2 课在流程层面做了 ECRS（取消/合并/重排/简化），本课则在动作层面再做一次"ECRS"——把减少流程级浪费的方法，翻译到手指级颗粒度。

## 小结与延伸阅读

**小结**：

1. 动素研究是用 17 种基本动作把手工操作"原子化"，让一切浪费无所遁形；
2. 双手图用最简单的时间对齐，把"单手空闲"和"寻找/选择"直接暴露在桌面上；
3. 改善的原则是 ECRS × 双手对称——先消除、再合并、再重排、最后简化；
4. 动作标准必须再回到秒表验证，形成"动作→时间→标准→培训→考核"的闭环。

**延伸阅读**：

- Gilbreth, F. B. 《Motion Study》(1911)——动素研究的开山之作；
- Niebel, B. W. & Freivalds, A. 《Methods, Standards, and Work Design》（第十三章 Two-Hand Process Charts）——当代标准教材；
- 现场工具：可访问 [a] 双手图表单（IE 协会模板 PDF）、[b] MTM（Methods-Time Measurement）动素时间表，把每个动素预赋值 UMS 单位。
